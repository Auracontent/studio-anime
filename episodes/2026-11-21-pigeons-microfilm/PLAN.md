# Plan de tournage : « Les pigeons du siège » (46,16 s, 1385 images, 30 i/s)

Objet clé : le pigeon et son microfilm (gros plan à l'accroche, balance film/plume), qui change d'état : vole -> plie sous le paquet -> film minuscule -> compté 300 -> 59 -> projeté sur le mur.
Test sans le son : pigeon qui vole avec un film brillant -> Paris sous la neige, soldats -> postier les bras en l'air, boîte vide -> ballon chargé de cages -> pigeon qui rentre -> pigeon écrasé par un paquet -> pile de lettres -> idée -> page photographiée qui rapetisse -> balance film/plume -> envol dans la neige, faucon -> grille 300 qui se vide jusqu'à 59 -> film projeté et recopié -> compteur 100 000+ -> la boucle (pigeon, plume qui tombe).
